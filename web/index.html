如何理解这些数字

连接记录按连接 ID 去重；错误来自核心警告日志，不能相除得到失败率。连接存在时间不是访问延迟。

复测能说明什么

路由器分别经直连、JP、HK 请求域名首页的 HTTPS HEAD，各 3 次。收到响应不代表业务成功，403 等也可能计为可达；复测不会切换节点或修改规则。
