MADE FOR EVERYDAY USE

先弄清楚，再做调整。

连接、探测和业务成功，是三件不同的事。Route Monitor 把这些证据逐层呈现。

01

从真实错误出发。

持续接收 Mihomo 连接快照和结构化警告，保留域名、出口与错误类别。默认待处理清单聚焦真实新错误。

02

让路径有可比性。

对同一个目标分别核对直连与代理路径，保留每次结果。证据不足、HTTP 拒绝或出口结论不一致时，保留不确定性。

03

纠偏，有明确归属。

可选的持续纠偏使用分时取证、发布前检查、终端回读与定向撤回。保护人工规则和设备的出口选择。

KNOW BEFORE YOU START

把边界，
也说清楚。

使用前了解版本、兼容范围与数据含义。
有具体问题，欢迎在 GitHub 提交反馈。

装好就会自动改规则吗？

不会。持续纠偏默认关闭。观察、预检和允许发布是不同模式；网页不能把观察模式直接升级为自动模式。启用前需要配置并核验路由器桥接和规则服务。

探测成功，是否代表 App 已经恢复？

不代表。探测只覆盖相应路径与协议，不能证明登录、视频、推送或 App 业务成功。连接计数也不是请求数或失败率。

会保存浏览内容吗？

程序不保存原始流量日志、URL 路径、Cookie 或业务请求内容。域名与连接历史保留在运行它的 Mac 上；访问本地页面需要密码。

可以部署成公网监控平台吗？

这个项目面向可信局域网，不应暴露公网或配置端口映射。Mac 退出登录、休眠或断网时，无法补抓缺失连接；绕过代理核心的设备也不在覆盖范围内。
